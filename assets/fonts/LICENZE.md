# Font inclusi

File woff usati solo per generare le immagini OG condivisibili
(`/api/og/...`), letti dal filesystem lato server.

- `silkscreen-latin-700-normal.woff`: Silkscreen di Jason Kottke
- `fraunces-latin-700-normal.woff`: Fraunces di Undercase Type
- `inter-latin-600-normal.woff`: Inter di Rasmus Andersson

Tutti e tre sono distribuiti con licenza SIL Open Font License 1.1,
che ne permette la redistribuzione. Provenienza: pacchetti Fontsource
(fontsource.org), che impacchettano i file di Google Fonts.
